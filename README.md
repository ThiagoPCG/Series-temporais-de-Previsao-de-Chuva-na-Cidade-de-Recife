🌧️ Previsão de Chuvas em Recife com Séries Temporais

Projeto desenvolvido para análise e previsão de precipitação pluviométrica na cidade do Recife utilizando técnicas de Séries Temporais e o modelo Facebook Prophet.

O sistema realiza:

análise histórica de chuvas
identificação de sazonalidade
previsão para os próximos 12 meses
visualização interativa dos dados
📌 Objetivo

O objetivo do projeto é prever o comportamento das chuvas na cidade do Recife utilizando dados históricos simulados com base em padrões climáticos reais da região.

A aplicação busca demonstrar conceitos de:

séries temporais
sazonalidade
previsão estatística
visualização de dados
análise climática

🧠 Tecnologias Utilizadas
Python
Streamlit
Pandas
NumPy
Prophet
Plotly

📊 Funcionalidades

✅ Geração de dados históricos de chuva
✅ Simulação de sazonalidade anual
✅ Previsão de precipitação para os próximos 12 meses
✅ Dashboard interativo
✅ Visualização gráfica dinâmica
✅ Interface moderna utilizando Streamlit

📅 Período Analisado
Tipo	Período
Dados históricos	2016 - 2025
Previsão	2026

🌧️ Comportamento da Série Temporal

Os dados simulam padrões climáticos típicos da cidade do Recife:

maior volume de chuvas entre abril e julho
períodos mais secos no verão
variações aleatórias para tornar os dados mais realistas

📈 Modelo Utilizado

O projeto utiliza o modelo Prophet, desenvolvido pelo Facebook, especializado em:

previsão de séries temporais
identificação automática de sazonalidade
análise de tendências
previsões robustas

🚀 Como Executar o Projeto
1️⃣ Clonar o repositório
git clone <url-do-repositorio>

2️⃣ Entrar na pasta do projeto
cd projeto_chuva_recife

3️⃣ Instalar as dependências
python -m pip install -r requirements.txt

4️⃣ Executar o projeto
python -m streamlit run app.py
